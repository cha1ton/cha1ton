## 🚀 Proyecto destacado

### 🌐 ServiciosPE — Plataforma de servicios cercanos

Aplicación web para buscar y recomendar servicios locales en Perú mediante geolocalización.

- Búsqueda de negocios y servicios según la ubicación.
- Registro de negocios e información de contacto.
- Asistente con IA integrado mediante **DeepSeek y OpenRouter**.
- Frontend con **Next.js**; API con **Node.js y Express**; datos en **MongoDB**.

**[Explorar demo de ServiciosPE](https://serviciospe.vercel.app/)**

> Proyecto académico desarrollado en 2025. La disponibilidad de la demo depende del despliegue.
